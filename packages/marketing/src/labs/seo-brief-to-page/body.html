Plan a page that helps someone do something.

Build a practical brief for an article, service, tool, event, course, campaign or portfolio page. Start with audience need and page purpose; then use search, structure, linking, metadata and structured data to make that useful page easier to discover.

◎
SEO is useful information design. The aim is not to force keywords into a page. It is to help the right audience find clear, accurate, credible information and take an appropriate next step.
